# مختبر البرومبت — نسخة أندرويد المحلية (المرحلة الثانية)

تطبيق أندرويد أصلي (Kotlin + Jetpack Compose + Room) ينفذ المسار المحلي الكامل من خطة «مختبر البرومبت»: اكتب طلبك بلغتك العادية ← شاهد ما فُهم منه ← احصل على برومبت قابل للنسخ. **كل شيء يعمل على الجهاز بلا إنترنت، ولا يُرسل نصك إلى أي جهة.**

## ما في هذه النسخة (نطاق المرحلة الثانية)

- **شاشة الإدخال** مع قبول النص من قائمة المشاركة في أندرويد (`ACTION_SEND`, text/plain) — بلا اقتصاص حتى ٨٠٠٠ حرف عمليًا.
- **التحليل المحلي الفوري**: نموذج نص مسبق الاستخراج + ١٢ قاعدة تحليل منقولة بتكافؤ مُقاس من محرك Prompt Rerank المرجعي + القوائم العربية (تطبيع، أرقام بالخانتين، تعارض منطقي، لهجات، نص مختلط، كلمات مهاد).
- **التنقيط**: عقوبات وأوزان المحرك المرجعي نفسها (ناتج ٠–١٠٠).
- **ملخص النية والقيود** قابل للمراجعة + **أسئلة توضيح اختيارية** (≤ ٣ في جولة واحدة، قابلة للتخطي، والتخطي يعطي عنصرًا نائبًا لا قيمة مختلقة).
- **مولّد القوالب المحلي** بثلاثة أوضاع: تحسين / اختصار / نسخة مفصلة — القيود الصريحة تُنقل حرفيًا، والطلب البسيط يبقى كما هو.
- **فحص تغطية القيود** داخل الناتج (✓/✗ لكل قيد) وكاشف انتهاك المنع (للاستخدام مع مخرجات النموذج لاحقًا).
- **السجل والمفضلة** في Room: حفظ اختياري، نسخ، مشاركة، حذف عنصر، حذف الكل، تعديل النتيجة مع بقاء الأصل.
- **المسودة** تُحفظ تلقائيًا وتُستعاد بعد قتل التطبيق أو تدوير الشاشة.
- **عربية RTL أولًا** (`values-ar` كأساس + إنجليزية) وعرض آمن للنص المختلط.

## ما لا في هذه النسخة (متعمد، حسب الخطة)

- لا خدمة سحابية ولا مزود تحسين ذكي — **لا صلاحية `INTERNET` في الـ Manifest أصلًا**، فخصوصية المسار المحلي مضمونة بنيويًا لا بالاختبار فقط (NFR-01). تُضاف الصلاحية مع المزود الواحد في المرحلة الثالثة.
- لا حساب ولا تسجيل دخول ولا تحليلات.
- المقارنة الفعلية (مختبر المقارنة) مؤجلة للإصدار التالي كما في الخطة.

## البناء والتشغيل

المتطلبات: Android Studio Ladybug أو أحدث (أو JDK 17 + حزمة SDK 35).

```bash
# في Android Studio: Open → مجلد المشروع → انتظر المزامنة → Run ▶
# أو من السطر البرمجي:
./gradlew assembleDebug          # يولد app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest      # يشغل الاختبارات الـ 27 (نواقل التكافؤ + العربية)
```

التثبيت المباشر على الجهاز: فعّل «مصادر غير معروفة» ثم ثبّت `app-debug.apk`، أو `adb install -r app/build/outputs/apk/debug/app-debug.apk`.

## اختبار وضع الطيران (شرط انتقال المرحلة)

1. فعّل وضع الطيران قبل فتح التطبيق.
2. اكتب: «أبي إعلان لدورتي في إنستغرام، باللهجة السعودية، لا تذكر السعر».
3. راجع ملخص الفهم والسؤال المؤثر (تخطّيه يظهر `[اسم الموضوع]`).
4. ولّد، انسخ، جرّب وضع الاختصار — المسار كله يعمل وصفر باقات شبكة (الصلاحية غير موجودة أصلًا).

## بنية المشروع

```
app/src/main/java/com/promptlab/app/
├── engine/            محرك نقي بلا أي اعتماد أندرويد (يُختبر على JVM)
│   ├── TextModel.kt          نموذج النص + التطبيع العربي (نقل مطابق + AR-01/02/05/06)
│   ├── Analyzers.kt          القواعد الـ 12 + أزواج التعارض العربية (AR-03)
│   ├── TaskType.kt           كشف نوع المهمة والتعقيد (بمفاتيح عربية)
│   ├── Scoring.kt            التنقيط (نقل مطابق لـ scoring.ts)
│   ├── PromptAnalyzer.kt     الواجهة + فهرس العرض العربي للنتائج
│   ├── Constraints.kt        استخراج القيود الصريحة + التغطية + الانتهاك + اللهجات (AR-04)
│   ├── Clarify.kt            الأسئلة التوضيحية (≤ 3، قابلة للتخطي)
│   ├── TemplateGenerator.kt  المولد المحلي بثلاثة أوضاع
│   └── Diff.kt               فرق نصي كلمة-كلمة (LCS)
├── data/PromptLabDb.kt       Room: السجل والمفضلة والمسودة
├── ui/Screens.kt             شاشات Compose الأربع
├── MainActivity.kt           الإدخال المباشر + المشاركة من التطبيقات الأخرى
└── PromptLabApp.kt
app/src/test/java/.../engine/
├── EngineParityTest.kt       النواقل الـ 11 بالقيم المرجعية المقاسة
└── ArabicAcceptanceTest.kt   16 اختبارًا من حالات قبول المرحلة الأولى (A01…G05)
```
